## 界面更新（2026-09-27）

总目录和八个科目共用搜索、年份及题卷类型筛选，支持清空筛选、无结果提示、分批展示和最近阅读入口。每份资料继续提供 SVG 原版与 LaTeX 重排版。

全部 670 个阅读页共用返回目录、版本切换、目录/页码跳转、字号/宽度或 SVG 缩放、专注阅读及阅读进度。设置保存失败时仍可正常阅读。`file://` 下不同页面能否共享最近阅读记录取决于浏览器，尚未实机验证。

右上角第三档“并排对比”在同一窗口展示两版：宽屏左侧 SVG、右侧 LaTeX，窄屏上下排列，各自独立滚动。点击当前版本名称或“退出对比”恢复原单版阅读位置；另一版本名称进入对应单版。嵌入窗口不递归加载对比，也不覆盖单版阅读进度。若浏览器不展示本地嵌入文档，可使用每栏“单独打开”入口。

共享 UI 通过 `enhance_readers.py` 注入，13 个生成器已接入；正文 HTML 和公式不重写。更新后的 HTML 散列已回写各资料清单。旧 HTML、生成器及清单备份位于 `work/before-ui-redesign/`。`ui-verification.json` 记录去除 UI 注入后与备份的逐字节比较。

本轮浏览器自动验收被 URL 安全策略拒绝（不允许访问本地 `file://`），即使用户已授权仍未放行。DOM 检查不等于真实浏览器显示验收；未通过本地服务或其他浏览器绕过。以下导入统计和散列是历史记录，当前界面改动以本节及 UI 核验文件为准。
