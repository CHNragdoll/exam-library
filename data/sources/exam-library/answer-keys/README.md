# Public English answer letters

The private `.local/answer-keys/burningvocabulary.json` records the free “查答案” letter grids shown on the public pages at [英语真题在线](https://zhenti.burningvocabulary.cn/). It covers the site's Kaoyan English, CET-4, and CET-6 listings as captured on 2026-09-29. It contains answer tokens and source URLs, not paid explanations or PDF contents. The private path is outside the static reader's document root and is Git-ignored.

To refresh the Kaoyan/CET capture, run `node scripts/fetch_english_answer_keys.cjs` from the repository root. The fetcher checks the public reader worker's SHA-256 before running it; a changed worker requires review and an explicit hash update. For TEM4/TEM8, `node scripts/fetch_tem_answer_keys.cjs --audit` checks the eight public grids and the exact source PDF hashes without writing files; `--write` saves a separate private manifest after review. Rebuild with `.venv/bin/python scripts/build_structured_exams.py` and `.venv/bin/python scripts/build_question_database.py` only when generated-data changes are authorized.

The structured builder attaches a letter only when the paper ID and question number match uniquely. Where a question has individual printed choices, the letter must match them. For CET Section B shared paragraph banks, letters beyond O must appear in that paper's printed bank. TEM additionally requires the captured PDF SHA-256 to match the canonical original PDF, and word-bank cloze requires a complete 15-letter printed bank and a verified blank number. Supplementary TEM4 sets with duplicate question numbers remain unanswered. Existing explicit answers are preserved. Empty or ambiguous source keys remain unknown. The latest reconciliation counts are in `../structured/public-english-answer-audit.json`.
