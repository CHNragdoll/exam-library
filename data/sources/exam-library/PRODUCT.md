# Offline Exam Library

Register: product.

供项目所有者在Mac本机离线查找历年试题并连续阅读。当前8类、335份文档、每份SVG原版和LaTeX重排两种阅读入口。范围仅本题库，不是Anki卡片模板。

主要流程：选科目和年份→选试题/解析→打开适合的阅读版本→跳章节、调整阅读宽度/字号、切换版本。正文、图表和下载源码是核心，操作界面服务于查题和阅读。

保持现有file://离线使用，零外部字体和服务依赖；原始PDF及转录正文不修改。SVG保持原卷版式，重排保留已确认的正文两端对齐、短选项左对齐、公式display风格、题干/插图正确顺序。已清理广告不得恢复。

视觉：白色阅读区，蓝色操作与状态提示，中性色导航；不用大幅装饰或进场动画。键盘可用，触屏目标清晰，窄窗可读，减少动态效果。原稿异常/残页说明保留。
