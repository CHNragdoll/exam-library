# 英语真题 · 可重排 HTM 与 LaTeX

打开 [全部考试](index.htm)。五类公开试卷与原归档对应：考研 44 套、四级 71 套、六级 83 套、专四 4 套、专八 4 套，共 206 套、2020 个原卷页面。

## 使用

- 浏览器打开 `index.htm`，按考试及年份进入试卷。无需联网或运行服务。
- 正文是 HTML 文本，随着窗口宽度换行；可选中复制。短选项按“题号＋A＋B＋C＋D”同行显示，窄窗口可在该行横向滚动；长选项继续自动换行。
- 每份试卷顶部可下载 `.tex` 和结构化 `.json`。TeX 使用 XeLaTeX 和 `ctexart`；与同名 `.assets` 素材目录放在一起编译。
- 图表、漫画及复杂框图保留局部插图，随容器缩放，独立图题居中。7 处排序图保留原卷框线、字形和填空位置，使用 SVG 与对应矢量 PDF；其他插图保留原卷画面。
- 不显示原卷页码或分页横线；正文两端对齐，选项自然左对齐、填空数字居中，明确的跨页续句连续排版。原页位置仅在结构化 JSON 和 HTML 元数据中保留。

## 内容与限制

这是由原始文字层自动恢复段落、题号、选项和下划线的独立版本。英文正文并非整页 SVG；LaTeX 与 HTM 由同一份结构化内容生成。网页并非浏览器实时编译 TeX，文字重排由 HTML/CSS 完成。

部分旧卷原字体缺少 Unicode 映射，或 OCR 文字层与画面不符。受影响的区域保留原图（PNG），按窗口缩放，对应页有提示；这些区域暂不能重新断行或准确复制，也不是可编辑的 LaTeX 文本或矢量字形。正常正文仍是可重排文本。没有用 OCR 猜测替换原文。复杂图表、表格仍保留为独立插图。无法确定段落关系的跨页边界仍保留自然段分隔，避免误合并。

字符守恒检查只证明结构重组未丢失已提取的正文字符，不等于人工逐题校对，也不能证明原 PDF 的 OCR 文本层本身无误。原 SVG 版、原 PDF 和原始来源记录均未改动，可用于对照。

不含付费解析、听力音频；部分原档案的共享题目仍通过对应试卷链接访问。页面不显示原站网址，来源哈希保留在 `manifest.json`，上游来源归档不变。

## 验证与复现

`build.py` 从现有本地 PDF 归档重建；`tools/extract.py` 实现文字结构恢复。`verify.py` 检查本地链接、页面数量、字符守恒并编译全部 LaTeX。详细结果见 `verification.json` 和 `REVIEW.md`。

本轮没有浏览器实机交互测试；LaTeX 编译和局部素材目视检查不能替代浏览器验收。
