# 插图清晰化与人工审计

本轮检查 242 张实际插图：英语 72、408 153、数学三 12、政治 5。英文乱码字形回退块不作为插图重绘。

当前接入 28 张对比图：27 张内置 imagegen 重绘，以及 1 张用户明确要求的精确 SVG。模型具体版本由工具决定，没有通过 CLI 指定模型。`results.json` 保存候选处置、提示词、核对依据及接入图的哈希；三个 `*-audit.json` 是初步筛查记录，`results.json` 是第一轮历史记录，本轮修订以 `round2-results.json` 和当前 `image-redraws.json` 为准。清晰的矢量图和无法可靠确认细节的原图继续保留。

## 人工对照

打开 [原图与重绘对照页](../../data/sources/exam-library/image-review.htm)，或从题库目录侧栏进入“插图重绘对照审计”。支持按科目、状态、关键词筛选，放大原图/重绘图，标记通过或需修改，填写备注并导出 JSON。

所有条目初始为待检查。代码核对和代理图像复核不等于用户人工审计通过。浏览器可能拒绝 file:// 的本地存储，页面会提示；务必导出结果以保留意见。

阅读页默认展示已接入重绘图，可切回原图。图片加载失败自动保留原图；整页 SVG 原版不替换。

## 修正与保留

- 2016 年 408 拓扑图按原图修正 Switch 顶面四个箭头；保留原连接关系与地址。
- 2015 年 408 网络图多次生成仍改变设备内部箭头，拒收候选，保留原图。
- 两张链表图因生成改变指针结构而拒收。
- 2000 年英语作文图 1995 年水下改回一条完整的鱼，撤销上一轮误认鱼骨的结果；2019 年 408 答案进程图补齐 40—50 ms 矩形外框。
- 从英语原图裁片中拆出的字数要求、答题卡提示已恢复到可重排正文，并加入源文件回归检查。
- 真人照片及难以辨认的题意细节不作猜测性重绘；2002 年英语人物照片生成候选未接入。

## 验证边界

本轮完成本地图像检查、资源链接/清单核对、源文件回归和 jsdom 交互测试。未将这些检查报告成真实浏览器的视觉验收；该对照页供用户继续人工检查。

原始 PDF 和整页 SVG 保留。部分重排版原图素材裁去混入的题干，相关文字已迁回正文；对照页可通过“整页原版”查看未经此裁切的完整来源。

## 第二轮修订

5 张既有图修订，新增 7 张网络交互/拓扑图。信封保留原倾斜方向和手指遮挡，并修正邮票及地址线的位置；广播域/冲突域保留原始遮挡关系，同类边界与图例统一用色。卫星拓扑按用户提供的路由器局部原图保留 R1/R2 箭头方向与中央交叠，再仅作彩色化。

2025 年第 38 题 TCP 图使用 `scripts/build_2025_tcp_svg.py` 生成：时间轴、报文箭头、文字和时间点为原生 SVG，两个设备插图保留为内嵌位图。坐标检查保证长报文共享右侧端点、两条截断箭头不被错误延长。对比页右栏标记为“精确 SVG”。

对比页可点击“只看本轮修订”；图片内容哈希发生变化时，旧版通过状态自动重置为待检查，原备注保留。所有本轮图仍需用户人工确认，未宣称逐像素一致。失败候选不接入阅读页。
