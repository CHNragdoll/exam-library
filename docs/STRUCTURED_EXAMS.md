# 结构化试卷与排版模板

范围：`documents.json` 收录的全部 335 份题卷、合卷和答案卷，覆盖考研英语、四/六级、专四/专八、408、数学三和政治。此变更增加供刷题小程序和 PDF 渲染复用的规范化题库，并提供审阅页。不改原始 PDF、SVG 或重排卷正文。类型 `feature`，风险 `R2`：大批量解析可能将题干、选项或答案归错题，但原资料不受影响。

## 数据与排版合同

- 每份卷产生一个版本化 JSON 和一个结构化阅读页；另外生成全库 `question-bank.jsonl`。稳定 ID 来自目录中的卷 ID、题号和该题号在卷内的出现次数。
- 数据记录原卷、重排卷、原始选项标记、统一显示标记、源页码与源块位置。源块含纯文本、轻量富文本、公式 TeX 和图像引用；阅读页依原顺序保留每个源块，归属不明的块标注 `source_only`，不得猜造答案。
- 所有四选项题的模板显示标记为 `A.`、`B.`、`C.`、`D.`，即使原卷是 `（A）` 或 `A.`。原标记仍存于 JSON 的 `sourceLabel`。
- `templates.json` 按考研英语、四级、六级、专四、专八、408、数学三、政治分别定义试卷类别、章节顺序和选项列数；阅读页另有科目字体、响应式与打印样式。
- 题目记录固定包含题型、题干、选项、源块、源页，以及 `answer` 对象。`answer.value`（标准答案）、`solution`（解答过程）、`explanation`（解析）、`commentary`（点评）、`knowledge`（考点知识）互相独立；原卷未提供的字段为 `null`。答案来自显式答案卷或合卷答案段，并以答案卷 ID、题号和源块回溯，不从题干猜测。
- 目录只取结构化章节和题号，题号指向对应源块。已有重排阅读页也使用这份目录数据定位，避免把单独的 `1.` 当成章节标题；SVG 原版保留页码目录。

## 验收与恢复

1. 335 份目录资料各有 JSON 和阅读页，稳定 ID 无碰撞，源块计数与输出块计数相等；题库 JSONL 每条都能回溯试卷 JSON。
2. 每类抽样核对题号、题干、四个选项、公式和图表；答案卷核对显式答案和解析归属。
3. 全库 `audit.json` 汇总未识别或不完整题目和有来源的答案数。答案缺失、解析缺失是资料状态，不自动补齐；不能把机器审计通过等同于人工视觉验收。
4. 新版是附加目录；停止使用或回退时移除结构化入口即可，旧阅读页和原资料不需迁移。

本批只做本地可审阅结果。因属广泛数据格式改动，依项目约定在独立分支核查，集成前需要针对实际差异的审查。

生成命令：`./.venv/bin/python data/sources/exam-library/build.py`。独立校验：`./.venv/bin/python scripts/verify_structured_exams.py`。入口是 `data/sources/exam-library/structured/index.htm`；机器读取从 `structured/templates.json`、`structured/question-bank.jsonl` 和每卷 `structured/papers/<category>/<name>.json` 开始。当前结构化字段以 `exam-paper.v1` 为版本，不应把旧网页 DOM 当作小程序的数据接口。
