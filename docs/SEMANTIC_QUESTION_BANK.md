# 真题库语义模型与迁移约定

## 为什么不能把整页存成一个题块

原卷实际包含卷型、章节、共用材料、文章标题与段落、题干、小问、共用选项池、代码、公式、图、答案正文和跨卷引用。它们的关系因考试而异。单个 HTML/纯文本块无法可靠地回答“这段材料供哪些题使用”“选项原顺序是什么”“答案引用了哪一卷的哪一题”，也不能安全地用于乱序刷题或导出 Anki/PDF。

当前 `v2` 表保留原有 JSON 与 API 合同；新增 `question-bank.semantic.v3` 是可重建的语义层。**原始 PDF、HTML、来源块以及原 JSON 不随迁移丢弃或覆写。** 数据库生成时校验输入哈希、外键和完整性，先在临时文件内完成构建，再备份旧库并原子替换。若构建失败，旧库保持原样。

## 从真实卷型归纳的实体

| 实体 | 表或节点 | 用途与边界 |
| --- | --- | --- |
| 试卷及卷型 | `papers`, `paper_forms` | 数学三旧卷 IV/V 版、专业英语补充卷与普通卷不可只靠年份或题号区分；标题年份冲突保留待核，不猜测归属。 |
| 章节及材料 | `semantic_nodes` 中的 section、passage、material | 保留阅读文章与政治材料等共享上下文；题目通过 `semantic_links` 引用，不复制文章成多份。 |
| 段落及媒介 | `content_units` | 段落、说明、代码、公式、图分别存；原来源块和结构化字段可同时追溯，消费者应按用途选择呈现层，避免重复显示。 |
| 题目及小问 | `questions`, `semantic_nodes` 中的 question、subquestion | 一题多问保持顺序，编号不等于全库唯一标识；题干、材料、小问分开。 |
| 私有选项 | `options` | 保存稳定 ID、印刷标签和原始位置，乱序时只改变展示顺序。 |
| 共用选项池 | `choice_sets`, `choice_set_options`, `question_choice_sets` | 四/六级选词填空 A–O、段落匹配 A–L 等先记录共享池，再关联各小题；标签缺失或不可信时标为 unresolved。 |
| 答案及跨卷引用 | `answers`, `answer_references` | 原文、解析、显式答案和“同试卷 IV 第 N 题”分开保存；引用须按年份、卷型、章节、印刷题号定位，不能只按数字匹配。 |
| 来源与质量 | `source_spans`, `unit_provenance`, `quality_issues` | 每项可回到原 PDF 页/来源块/JSON 路径；当前 PDF 定位精度是块级，不能声称字符级。 |
| 可自动判分 | `scoreability` | 只有答案与选项安全匹配的题可自动判分。纯解析、答案引用或来源不确定的题保持人工核对状态。 |

## 已核实的边界案例

- 数学三 1987–1996 存在 IV/V 卷和重复题号；1990 V 卷第 4 题的引用要指向 IV 卷对应的第 4 题，而不是另一章节的同号题。1991 V 卷第 13 题同时有引用和本地答案，二者都要保留。
- 四/六级 Section A 的填空题号不能一律假定为 26–35：早年卷可能为 36–45。选项池可能与十个空共用；原卷缺标签时不能臆造。
- TEM4 2022 文件中出现印有 2023 年的补充卷标题。数据库保留两个卷型与年份冲突标记，待原卷范围核定后再决定归档。
- 政治 2023 第 35–38 题的材料跨页续印。`第 N 题（续）` 是同一题的延续，不是新题；小问应随材料保留各自边界。原答案的 `【答案】` 与 `【试题简析】` 属不同内容，不能混为一个段落。
- 有些英语 PDF 的文字层把一个词或一句话拆成短段，也会把章节标题粘到前一段。分段依据原 PDF 的题号、行距、缩进和印刷语义核实；仅凭“短”或标点自动合并会误伤真实段落。

## 数据使用与验收

`/api/v1` 保持兼容。`/api/v2` 可按试卷读语义树、按节点读材料，并通过显式答案路由取得答案。答案卷和题答混排卷的原始块边界未全部核清前，默认语义接口保守抑制可能泄漏答案的原始块并标明原因。新客户端应检查 `scoreability`/质量标记，而非仅凭 `answers.status = explicit` 判定可自动评分；数学三跨卷引用的旧 v1 字段仍是原文，并非已替换成独立可评分答案。

验收分三层：生成器/SQLite 校验保证数量、来源、引用、外键及回滚；接口测试保证题答隔离和旧接口兼容；抽样浏览器与 PDF 并排检查保证显示结构。自动检查与抽样不能代替 335 份原卷的逐页人工核对。每次源内容或规则改变后，应重新构建并重新记录三层结果。
