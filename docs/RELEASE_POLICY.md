# 发布约定

本项目使用 `MAJOR.MINOR.PATCH` 版本号。首次正式交付为 `v0.1.0`；后续兼容新功能提升次版本，兼容修复提升补丁版本，不兼容的数据或接口变更提升主版本。正式版本需在 PR 中同时更新 `package.json`、锁文件和 `CHANGELOG.md`，经相关检查及独立评审后合入 `main`，再从合入提交创建不可移动的注释标签及 GitHub Release。GitHub 自动生成的源码归档是版本交付物；本地生成的 SQLite、原始 PDF、工作缓存和备份不上传。

源 JSON/JSONL 是可移植题库数据；SQLite 是可重建的本地读取库。升级前如需保留旧库，应停服务并自行复制 `data/question-bank.sqlite3` 至仓库外的备份位置。若新版本不适用，切回先前提交并恢复对应数据库备份，或用该提交的结构化源重新建库。浏览器作答状态保存在本机浏览器，版本切换前应自行保留需要的作答记录。发布记录需列出验证结果、未核实数据、回退基线与截图的适用范围。
