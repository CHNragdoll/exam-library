# 原始 PDF 与题库逐卷核查记录（2026-09-28）

本轮把目录中的 335 份题卷、答案卷和合卷与 271 份唯一原始 PDF 建立来源校验；PDF 总计 2,832 页。对全量页面做自动文本、页码、题号、段落、选项、小问、答案引用检查，再按异常类型打开原 PDF 页面抽核。**这不是 2,832 页的人工逐页、逐字校对**：图片回退、公式和损坏文字层仍需视觉复核，自动报告中的线索不能直接等同于错题，也不能证明未报出的文字绝对无误。

- 政治 2010–2020 年第 34–38 题的 55 个答案关联、2020 年第 13 题缺失的解析、2022 年两处 OCR 标点，均按答案 PDF 核对修复。
- 408 计算机统考 2016–2023 年原答案 PDF：每年 47/47 题已关联答案。图形选项保留原图并提供独立选项。2020 年 PDF 末页误夹的 2019 年题干不作为 2020 年答案。

- 英语 206 份原 PDF、2,020 页做自动段落普查和局部原图核对；PDF 证实的英文选项漏拆已修 36 组，包括专四 2023 年第 14 题 B 项与四级 2020-12-01 第 12–15 题。正文首行缩进的生成规则已修正，避免把连续文字压成一段。详细页码、例外和校验见 [英语原 PDF 核对](ENGLISH_PDF_QUESTION_QA.md)。

## 原卷异常与仍需人工复核

- 原 PDF 自身的重复题号、缺印选项、异常标点保留来源字样，不凭常识补造。例如六级 2018-06-02 第 8 页第二个第 53 题印为 E/B/C/D，六级 2015-12-01 第 7 页第 56 题没有可确认的 D 项。
- 英语仍有 113 个重排时采用图片回退的页；其中已按原 PDF 和原 HTM 的可选 SVG 文字层恢复 18 页上的 82 张独立题卡；后续覆盖审计又补回 118 张漏卡。图片回退表示该页的 PDF 文字抽取或重排未满足可靠转录要求，**不表示原 HTM 是不可选字的扫描版**。对审计标出的 120 条局部回退段已逐条目检，另有未标出的回退内容仍需继续逐段确认；数学三 1987 年第 5/10 页抽字稀疏，经 PDF 画面核对题文完整。政治、408 的抽字稀疏页另在最终审计中保留线索。
- 目录未附答案 PDF 的卷保留 `missing`，来源不足以消歧的答案保留 `ambiguous`；不把未提供的答案猜成标准答案。查看答案面板和 SQLite 对外保留这些状态，避免后续刷题、Anki 或乱序版误判。
- [最终审计报告](SOURCE_INTEGRITY_AUDIT_FINAL_2026-09-28.md)和 [机器可读线索](source-integrity-audit-final-2026-09-28.json)记录未自动核销的候选。它们含答案页、听力原文、公式和印刷交叉引用造成的误报；可用 `documentId`、页码、源块 ID 回到原 PDF 继续核查。

## 重现与验证

生成：`./.venv/bin/python data/sources/exam-library/build.py`。来源审计：`./.venv/bin/python scripts/audit_source_integrity.py --json docs/source-integrity-audit-final-2026-09-28.json --markdown docs/SOURCE_INTEGRITY_AUDIT_FINAL_2026-09-28.md`。结构校验：`./.venv/bin/python scripts/verify_structured_exams.py`。测试：`./.venv/bin/python -m unittest discover -s scripts -p 'test_*.py'`、`npm test`。

原 PDF 和来源哈希保持不变；结构化 JSON、阅读页和 SQLite 是由源文件重建的派生产物。发生解析回归时可恢复生成器并重建，原卷无需迁移。
